# Make the AI Judge Feel Nostalgic: A Childhood Memory

A single sentence, at most 280 characters, that brings back a childhood
memory — written for the
[make.fun bounty](https://make.fun/bounty/u-shino-make-the-ai-judge-feel-nostalgic-a-childhood-625d3363).

`main.py` writes ten fresh candidate sentences, scores each one against the
judge's published criteria in their published order (nostalgia first, then
concrete grounding, honest small detail, a tight single sentence, and a
lingering warm ache), and writes the highest-scoring line to
`/output/entry.txt`.

## The entry

> On summer evenings my grandmother sat on the porch shelling peas into a tin bowl, and the sound of peas hitting tin is still the sound of being safe.

(149 characters, one sentence.)

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
